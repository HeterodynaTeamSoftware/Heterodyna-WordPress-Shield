# Security / Bezpieczeństwo

PL: Zgłaszaj podejrzenia podatności prywatnie do opiekunów projektu przez GitHub (Security Advisories, gdy dostępne), nie publikuj exploitów ani prawdziwych kluczy w issues. Nagłówki i endpointy należy przetestować w środowisku staging; wtyczka nie zastępuje WAF, patchowania WordPressa ani backupów.

EN: Report vulnerabilities privately to maintainers via GitHub Security Advisories when available. Never attach real credentials to public issues. Test policies and endpoints on staging; this plugin is not a WAF or a replacement for patching/backups.
